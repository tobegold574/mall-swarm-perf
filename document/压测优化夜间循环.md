## 2026-10-09 10:1x 重大发现：brand_update 相位测的是鉴权拒绝路径
- 无 token 请求返回 **HTTP 200 + body code:401**（网关过滤器模式）→ JMeter 判成功 → brand_update 相位 0% 错误率是假的
- 该相位实际测的是「鉴权拒绝路径」的吞吐，不是品牌更新——0 条 UPDATE 被 digest 差分证实
- 修复：admin_brand_update.jmx body 带齐校验字段（name/logo/brandStory）+ ADMIN token 头，手动验证更新成功（data:1，DB brand_story 已变）✓
- 待办：重跑 brand_update 相位（4 个，SKIP_DIGEST=1）拿真实写路径数据
- 教训入档：**业务层错误包裹在 HTTP 200 里时，JMeter 错误率完全失明**——写端点的有效性必须用数据库实变验证，不能信 HTTP 状态码
