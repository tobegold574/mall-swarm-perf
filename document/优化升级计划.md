| 决策 | 内容 |

## 踩坑记录（复用价值）

- JMeter 元素注册名看 saveservice.properties：barrier 是 `SyncTimer` 不是 SynchronizingTimer；根元素是 `jmeterTestPlan`
- JMeter 容器堆：jmeter 脚本自带 HEAP="-Xms1g -Xmx1g"，覆盖用 HEAP 环境变量，传 JVM_ARGS 会初始>最大冲突
- CSVDataSet 一行一个值，逗号拼接单行=整行被当成一个变量（曾致 199×HTTP400）
- compose 相对路径（build context / 卷挂载）按 compose 文件目录解析，本仓库需 `../..`
- zsh 下 `rm xx*` 无匹配会中止整条命令；pkill 模式串会匹配自身命令行
- npm 必须 npmmirror 源（官方源 39KB/s 龟速）；容器内 node_modules 用命名卷隔离，避免 alpine(musl) 与宿主(glibc) 的原生二进制混装
- JMeter 元素注册名看 saveservice.properties；CSVDataSet 一行一个值

## 构建注意事项

- 打包必须加 `-Ddocker.skip=true`：fabric8 docker-maven-plugin 默认连远程 Docker `192.168.3.101:2375`（prod残留），不加会超时报错
- 完整命令：`mvn -pl mall-common,mall-mbg,mall-admin,mall-portal,mall-gateway,mall-auth -am package -DskipTests -Ddocker.skip=true`
- 改代码后的部署：`docker compose -f document/docker/compose-local.yaml up -d --build`（会重建应用镜像并滚动重启）
- compose 的 build context 是 `../..`（compose 文件在 document/docker/ 下两层深，曾踩坑写成 `..`）
